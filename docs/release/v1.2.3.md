# Codex Synced 1.2.3

This Windows acceptance build simplifies packaging and tightens the WPF desktop UI.

## Changes

- Reworked the Windows UI toward a denser desktop utility layout instead of a macOS-style large-card layout.
- Reduced panel radius, shadows, header sizes, and vertical spacing to avoid oversized sections and constant scrolling.
- Fixed home actions so primary and secondary buttons align in one row without duplicate scan actions.
- Fixed settings counters with a fixed-width stepper so the number no longer collides with +/- buttons.
- Removed the setup launcher and multi-language MSI bundle.
- Windows packaging now produces one English MSI and one portable ZIP.

## Local Acceptance

Build local packages before publishing:

```powershell
.\Windows\scripts\package-local.ps1 -Version 1.2.3
```

The MSI is English-only. The app UI still supports Chinese and English after installation.
