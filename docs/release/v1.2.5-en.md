# Codex Synced 1.2.5

English | [中文 ->](https://github.com/saymyzj/codex-session-synced/blob/main/docs/release/v1.2.5.md)

Codex Synced 1.2.5 replaces the old broad "align history to the active provider" strategy with a safer sidebar-summary repair flow. Provider values are now repaired only when rollout metadata proves the SQLite row is wrong.

## Fixes

- Renamed the Chinese backup mode label to "轻量备份" across the app and docs.
- Repairs sidebar rows that show as "New conversation" by writing short titles when `threads.title` is empty or equal to `first_user_message`.
- Restores conversation ordering from rollout JSONL timestamps by repairing SQLite update timestamps and rollout file mtimes.
- Rebuilds `session_index.jsonl` instead of only appending missing rows.
- Repairs local UI state in `.codex-global-state.json`, including stale `remote-control:*` selection, auto-connect entries, and missing `project-order` roots.
- Keeps rollout content unchanged in the main repair flow.
- Updates Windows to use the same safer repair strategy and self-test scenario.

## Safety

Codex Synced only repairs local sidebar summary and history visibility data. It does not modify OAuth tokens, API keys, third-party API URLs, provider configuration, or conversation bodies, and it never uploads local history.
