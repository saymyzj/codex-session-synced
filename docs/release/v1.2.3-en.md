# Codex Synced 1.2.3

English | [中文 ->](https://github.com/saymyzj/codex-session-synced/blob/main/docs/release/v1.2.3.md)

Codex Synced 1.2.3 is the accepted Windows follow-up build. It focuses on Windows desktop layout fixes and installer behavior. The installer now ships as a single English MSI, with a portable ZIP also available. The app UI still supports both Chinese and English after installation.

## Downloads

| System | File | Description |
| --- | --- | --- |
| Windows x64 | `Codex-Synced-Windows-x64-1.2.3.msi` | Recommended English installer with install path selection and Start menu integration |
| Windows x64 | `Codex-Synced-Windows-x64-1.2.3.zip` | Portable app directory for users who do not want to install |
| macOS | `Codex-Synced-macOS-1.0.1.dmg` | Uses the verified macOS 1.0.1 build |
| All platforms | `SHA256SUMS.txt` | SHA-256 checksums |

## Windows Fixes

- Adjusted the Windows WPF UI into a denser desktop utility layout instead of copying the large macOS-style card layout.
- Reduced sidebar width, heading sizes, card radius, shadows, and vertical spacing to avoid unnecessary scrolling.
- Added a fallback path for the content area to avoid blank views.
- Fixed the language switch selected state so the blue segment no longer disappears after toggling.
- Fixed the settings steppers so values no longer collide with the `+/-` buttons.
- Reworked home actions into one aligned row without duplicate scan buttons.

## Installer Changes

- Removed the `setup.exe` launcher so two installer wizards no longer appear.
- Removed the multi-language MSI bundle and kept one English MSI.
- The MSI wizard supports choosing the install path.
- The same `UpgradeCode` is preserved, so newer versions upgrade the older one instead of installing side by side.
- The local packaging script now writes to `artifacts/local` to keep build outputs tidy.

## Local Acceptance

Before publishing, the Windows MSI and ZIP were built locally and checked:

- Windows self-test passed.
- MSI passed WiX validation.
- MSI decompile confirmed an English installer wizard with install path selection.
- ZIP no longer contains `setup.exe` or multi-language installer directories.

## Usage

1. Quit Codex.
2. Download and install `Codex-Synced-Windows-x64-1.2.3.msi`.
3. Open `Codex Synced` from the Start menu.
4. Review the detected provider and pending changes.
5. Select a backup mode and apply the repair.
6. Reopen Codex and verify that local history is visible.

## Safety

Codex Synced only repairs local history visibility data. It does not modify OAuth tokens, API keys, third-party API URLs, provider settings, or message bodies, and it never uploads local history.
