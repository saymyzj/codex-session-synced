# Codex Synced 1.2.4

English | [中文 ->](https://github.com/saymyzj/codex-session-synced/blob/main/docs/release/v1.2.4.md)

Codex Synced 1.2.4 tightens the pending repair preview and aligns Windows and macOS release versions. The preview list now shows only a single-line conversation title and provider change instead of expanding message bodies, internal IDs, or local paths.

## Downloads

| System | File | Description |
| --- | --- | --- |
| Windows x64 | `Codex-Synced-Windows-x64-1.2.4.msi` | Recommended English installer with install path selection and Start menu integration |
| Windows x64 | `Codex-Synced-Windows-x64-1.2.4.zip` | Portable app directory for users who do not want to install |
| macOS | `Codex-Synced-macOS-1.2.4.dmg` | macOS build using the same version number as Windows |
| All platforms | `SHA256SUMS.txt` | SHA-256 checksums |

## Fixes

- Reduced pending repair previews to a single-line title so long conversation bodies no longer expand the page.
- Preserved provider change details while hiding local paths and internal IDs from preview rows.
- Aligned Windows and macOS release versions to avoid ambiguity on the downloads page.
- Reworked the release workflow into one manual dispatch that builds Windows MSI, ZIP, and macOS DMG files together.
- Kept a single English MSI wizard while preserving Chinese and English switching inside the app.
- Fixed an upgrade path that could leave the self-contained .NET runtime files missing after installation.

## Safety

Codex Synced only repairs local history visibility data. It does not modify OAuth tokens, API keys, third-party API URLs, provider settings, or message bodies, and it never uploads local history.
