# Codex Synced 1.1.0

English | [中文 →](https://github.com/saymyzj/codex-session-synced/blob/main/docs/release/v1.1.0.md)

Codex Synced 1.1.0 adds a native Windows desktop build. macOS and Windows downloads now live in one unified Release.

## Downloads

| System | File | Description |
| --- | --- | --- |
| Windows x64 | `Codex-Synced-Windows-x64-1.1.0.exe` | Recommended portable single-file app |
| Windows x64 | `Codex-Synced-Windows-x64-1.1.0.zip` | ZIP archive |
| macOS | `Codex-Synced-macOS-1.0.1.dmg` | DMG installer using the verified macOS 1.0.1 build |
| All platforms | `SHA256SUMS.txt` | SHA-256 checksums |

## Windows Highlights

- Reads `%USERPROFILE%\.codex` by default, with a configurable path in settings.
- Detects the latest `state_*.sqlite` database dynamically.
- Previews SQLite provider rows, rollout metadata, and missing index entries.
- Creates a lightweight or full backup before writing.
- Restores previous backups.
- Uses the Windows system SQLite library and ships as a self-contained single EXE.

## Usage

1. Quit Codex.
2. Download and run the file for your platform.
3. Review the detected provider and pending changes.
4. Select a backup mode and apply the repair.
5. Reopen Codex and verify that local history is visible.

## Safety

Codex Synced only repairs local history visibility data. It does not modify OAuth tokens, API keys, third-party API URLs, provider settings, or message bodies, and it never uploads local history.
