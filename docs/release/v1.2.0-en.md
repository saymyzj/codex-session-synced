# Codex Synced 1.2.0

English | [中文 ->](https://github.com/saymyzj/codex-session-synced/blob/main/docs/release/v1.2.0.md)

Codex Synced 1.2.0 rebuilds the Windows app. The Windows version no longer uses the temporary WinForms UI and no longer ships only as a single-file EXE. It now uses WPF and includes an MSI installer.

## Downloads

| System | File | Description |
| --- | --- | --- |
| Windows x64 | `Codex-Synced-Windows-x64-1.2.0.msi` | Recommended installer with Start menu integration |
| Windows x64 | `Codex-Synced-Windows-x64-1.2.0.zip` | Extracted app directory for users who do not want to install |
| macOS | `Codex-Synced-macOS-1.0.1.dmg` | DMG installer using the verified macOS 1.0.1 build |
| All platforms | `SHA256SUMS.txt` | SHA-256 checksums |

## Windows UI Changes

- Rebuilt the window layer in WPF to avoid the clipping, layout drift, and default table styling from the previous WinForms build.
- Matched the macOS visual language: light sidebar, white soft panels, rounded cards, gentle shadows, and blue primary actions.
- Added interaction motion: page slide/fade transitions, button press scaling, hover lift, activity strip, and bottom-right notices.
- Replaced default system DataGrid views with card-style pending repair and backup previews.
- Windows now ships as an installer-first desktop app.

## Usage

1. Quit Codex.
2. Download and install `Codex-Synced-Windows-x64-1.2.0.msi`.
3. Open `Codex Synced` from the Start menu.
4. Review the detected provider and pending changes.
5. Select a backup mode and apply the repair.
6. Reopen Codex and verify that local history is visible.

## Safety

Codex Synced only repairs local history visibility data. It does not modify OAuth tokens, API keys, third-party API URLs, provider settings, or message bodies, and it never uploads local history.
