# Codex Synced 1.1.0 for Windows

This release adds a native Windows desktop app for repairing Codex conversation history visibility after switching providers.

## Download

- `Codex-Synced-Windows-x64-1.1.0.exe`: portable single-file app for 64-bit Windows.
- `Codex-Synced-Windows-x64-1.1.0.zip`: the same app in a ZIP archive.
- `SHA256SUMS-windows.txt`: SHA-256 checksums for verification.

## Usage

1. Quit Codex.
2. Run `Codex-Synced-Windows-x64-1.1.0.exe`.
3. Review the detected provider and pending changes.
4. Open `待修复项`, choose a backup mode, then click `备份并修复`.
5. Reopen Codex and verify that the local history is visible.

The app defaults to `%USERPROFILE%\.codex`, detects the latest `state_*.sqlite` database automatically, and never modifies tokens, API keys, provider URLs, or conversation bodies.
